# なまえノート

子どもの名前候補をふたりで考えるための PWA（Web アプリ）。

- ひらがな読みごとに候補を登録し、漢字の候補・意味・画数の姓名診断（人格/地格/外格/総格・五行・言霊を ◎○△ で手入力）・懸念点を 1 画面で一覧化
- iPhone のホーム画面に追加してオフラインでも使える
- Firebase (Firestore) でふたりの端末を自動同期（任意設定）

## 使い方（iPhone）

1. 公開 URL を Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. **以後は必ずホーム画面のアイコンから起動する**（重要・下記参照）

### ⚠️ 必ずホーム画面のアプリから使ってください

iOS では、Safari のタブとホーム画面に追加したアプリは**データの保存場所が別**です。
さらに Safari のタブで使い続けると、7 日間使わなかった場合にデータが自動削除されることがあります。
ホーム画面に追加したアプリはこの対象外です。

### データのバックアップ

- 「データの書き出し・読み込み」画面から JSON をコピーして、メモアプリや LINE Keep に貼って保管できます
- 共有機能を使っている場合、候補データはサーバー（Firestore）にもあるため、端末データが消えても再同期で復元できます
- 共有の**招待リンクはふたりの LINE トークに残しておく**と、機種変更時の復帰に使えます

## 開発

- ビルド不要。`python -m http.server 8000` で起動し `http://localhost:8000` を開く
- `index.html` … アプリ本体（CSS/JS インライン）
- `sw.js` … Service Worker。**更新をデプロイするときは `CACHE_NAME` のバージョンを必ず上げる**
- `vendor/firebase/` … Firebase SDK v11.10.0（ESM）を同梱。`firebase-app.js` への import は相対パスに書き換え済み
- `docs/firebase-setup.md` … 共有機能の Firebase セットアップ手順

## プライバシー

- 名前候補のデータはこのリポジトリには含まれません（端末の localStorage と、設定した場合は自分の Firebase プロジェクトの Firestore にのみ保存されます）
- **共有ルームの ID・エクスポートした JSON は絶対にコミットしないでください**
- `index.html` 内の `firebaseConfig` は公開されても問題ない値です（保護はセキュリティルールが担います）
